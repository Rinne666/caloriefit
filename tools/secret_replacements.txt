# git-filter-repo 的替换规则文件模板
#
# 用法（把真实密钥写进本地副本，不要提交进仓库）：
#   1. 把本文件复制成 _tools/secret_replacements.txt（_tools/ 已 gitignore）
#   2. 写入要清除的字符串，格式：
#        literal:<原文>==>sk-REDACTED-FROM-HISTORY
#      literal: 前缀必须加 —— 不加默认按正则匹配
#   3. git filter-repo --replace-text _tools/secret_replacements.txt --force
#
# 本仓库里不保留任何真实密钥，包括本模板。
